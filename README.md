# IROS 2026 session grid

A single-page browser for the IEEE/RSJ IROS 2026 contributed-talk program
(Pittsburgh, 27 September – 1 October 2026).

- All 348 paper sessions across 23 rooms, filterable by day, format and topic
- Click any session to see its papers with titles, authors and keywords
- Search across sessions, paper titles and author names
- Pick talks to build a personal schedule, with clash detection and text export
- Workshop notes for Sunday 27 September and Thursday 1 October

Program data from <https://2026.ieee-iros.org/program/>.
